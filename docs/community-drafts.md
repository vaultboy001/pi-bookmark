## GitHub Discussion on earendil-works/pi (new, do not hijack #5244)

Title: Extension: pin important sessions (`pi-bookmark`)

Body:

```
If /resume has become a long untitled list, this extension keeps a short global pin list.

- /pin [note]  bookmark the current session
- /bookmarks   /resume-style picker of pins only
- ctrl+shift+b toggle

Uses /pin (not /bookmark) so it does not collide with pi-session-bookmarks / pi-session-librarian.

pi install npm:pi-bookmark
https://github.com/vaultboy001/pi-bookmark
https://pi.dev/packages/pi-bookmark
```
